# Evaluations

Dated records of agent runs against the toolkit, kept so later changes can be measured against them.

- `2026-10-09/maxroll-baseline/`: ground truth decoded from Maxroll's Erasing Strike Void Knight planner profile, and the scorecard of two blind opus agents (MCP only vs MCP + skills + knowledge) that built the same build without seeing the guide.
- `2026-10-09/original-build-challenge/`: two opus agents each produced an original build (mastery + damage source absent from all 74 community guides, core unique with zero usage, multi-part interaction, numeric model with calibration); `JUDGE.md` is an independent opus audit with scores and the toolkit findings that drove the following fix pass.
- `2026-10-09/user-case-lightning-fireball/`: a real player question (lightning Fireball, Harbinger of Stars, Liath's Machinations, Vilatria) answered in three rounds with mana-loop simulations.

Labels used throughout: A asset data, D decompiled code, G in-game guide, X community, U unverified.
